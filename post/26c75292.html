递进关系+拟人化搭配

人与人才斗智斗勇。

区分主客体。

命题人利用考生对近义词程度差异的模糊认知，将“递进关系”伪装成“并列关系”。

动宾短语

“苛刻”指条件严苛，“吝啬”指给予极少

“讨价还价”是拟人化表达，精准呼应前文将时间人格化的整体语境（“苛刻”“吝啬”均为人格化属性），体现“时间不因人的主观意愿而改变，人只能被动协商”的无力感，与“丧失信心”形成因果链条。

词义区分 搪塞，推诿，摆脱，推辞

“搪塞”常接“质疑、质问、问题”（如“搪塞记者”“搪塞上级”）态度问题！

“推诿”指“把责任推给别人”（如“推诿扯皮”），核心是转移责任归属

摆脱自身应承担的义务或过失

“推辞”指“拒绝接受（任命、邀请、馈赠等）

词义区分 啧啧称奇 大饱眼福 隐藏的思维定势

在描写具体物体表面折射时，“闪耀”比“散发”更具画面感和精准度

命题人精准拿捏考生看到“建筑”“艺术”“游客”就选“眼福”的思维定势

故意在句首植入“中西合井（中西合璧）”这一决定反应层级的核心定语——“合璧”意味着“罕见、新奇”，对应的反应应是“称奇”而非“饱眼福”。

“啧啧称奇”：“啧啧”为拟声词，表示赞叹声；“称奇”即“称奇道妙”。该词精确对应前文“中西合璧”带来的罕见、奇特、混搭的审美冲击，游客不仅仅是“看到美”，更是因“中西风格共处一院”这种反常搭配而发出惊叹。

散发”指“分散发出，向四周释放”，常用于气味（散发花香）、热量（散发温度）、光芒（散发光辉）等弥漫性事物

仅强调“视觉得到充分满足”，是中性或褒义的感官享受，不包含“惊奇”“罕见”之意。

“心旷神怡”：侧重“心境开阔、精神愉悦”，多用于自然风光（如“登高望远，心旷神怡”）。

“闪亮”多为形容词（“闪亮的明星”）或不及物动词（“闪亮登场”），较少直接接“光辉”作动宾结构

“拍案叫绝”：意为“拍着桌子叫好，形容对文艺作品或创意极其赞赏”，程度过重且对象通常限于“文章、见解、表演、创意”等高智力成果。

“打补丁”指在旧法上修补，“未雨绸缪”是时间上的提前准备，而非路径上的“另起炉灶”，二者不构成对立选择。

  1. “另起炉灶”：意为“另外重支炉灶，比喻放弃原来的，另搞一套”。与前文“在现有法律基础上‘打补丁’”形成路径对比
  2. “前瞻性”：直译“向前看”，指预先预见未来趋势并提前规划。与后文“走在技术前面”形成同义复现
  3. “未雨绸缪”：意为“趁着天没下雨，先修缮房屋门窗，比喻事先做好准备”。该词强调时间上的提前准备
  4. “重整旗鼓”：比喻“失败后重新整顿再起”
  5. “引领性”：强调“引导、带领他人跟上”，侧重导向作用

递进关系，不但—-更—-

  1. 抓递进结构：见到“不但……更……”“不仅……还……”等，重点看“更”“还”后的内容，那才是作者强调的重心。

  2. 排除“做法类”选项：若文段既有“做法”（协调发展）又有“本质/目标”（人民享有、命运共同体），问“意在强调”时优先选“本质/目标”层，而非“做法”层。

区分“总对策”与“具体手段”

    1. 定位总对策句：首句若出现“必须”“应当”“关键是”，其后为作者核心主张。
    2. 识别具体手段：若后文出现“通过”“利用”“借助”等词，其后的具体技术或方法仅为实现总对策的举例或路径，不能作为主旨概括。
    3. 选项甄别：正确选项应围绕总对策展开（如B“提升数字传播效率”），而非围绕具体技术手段（如C“离不开大数据”）。
  • “总对策—举例”结构识别：文段先提抽象主张，再用“比如”“例如”“通过”等引出具体实现方式，正确选项应锚定抽象主张。

倍数递推

类型 规律形式 示例
简单倍数 aₙ₊₁ = aₙ × k 2, 6, 18, 54… (×3)
倍数 + 常数 aₙ₊₁ = aₙ × k + b 3, 7, 15, 31… (×2+1)
倍数 - 常数 aₙ₊₁ = aₙ × k - b 5, 9, 17, 33… (×2-1)
变倍数 倍数本身成规律 4, 6, 10, 18… (+2,+4,+8)
三项递推 aₙ₊₂ = aₙ₊₁ × k + aₙ 1, 2, 5, 12, 29…

倍数递推的核心识别特征

  • 相邻项比值接近整数：计算后项除以前项的结果，如果得到 1、2、3、4 等整数或接近整数的数（如 1.5、2.5），优先考虑倍数递推。
  • 数列增长趋势明显：整体呈递增或递减趋势，且变化幅度较大（不是平缓增减）。
  • 存在”倍数 + 修正”模式：后一项 ≈ 前一项 × 倍数 ± 常数。
  • 看趋势——数列是否快速增长或下降？如果是，先想倍数或幂次。
  • 算比值：用后项除以前项，看商是否有规律（整数列、等差列、循环列等）。
  • 找修正：如果商不完全是整数，检查是否满足 aₙ₊₁ = aₙ × k + c 的形式，c 可能是常数或与项数相关的数。
  • 验三项：两项关系不明显时，尝试三项递推，如 a₃ = a₂ × k + a₁。

类型 规律特点 示例
反约分型 需将分数约分或通分后找规律 2/3, 4/6, 8/12… (实际是同一数列)

基础的排列组合

  • 排列（有顺序）：甲乙≠乙甲，如排队、选班长副班长、密码锁
  • 组合（无顺序）：甲乙=乙甲，如握手、从一堆里选人组队、买彩票选号
类型 公式 适用场景
排列数 P(n,m) = n!/(n-m)! 从 n 个里选 m 个排顺序 选代表发言、站队、排名次
组合数 C(n,m) = n!/[m!(n-m)!] 从 n 个里选 m 个不排顺序 选队友、抽奖品、分组
全排列 n!=Ann n 个元素全部排序 几个人坐几个座位
重复排列 nᵏ 可重复选取 密码锁、投球入盒

1. 捆绑法（相邻问题）

  • 特征：某些元素必须”挨着”
  • 做法：把捆绑的元素当”一个大元素”先排，再内部排序
  • 例：A、B必须相邻，5人站队 → 先把AB捆成1个，共4个元素排列 A(4,4)，再乘 AB内部排列 A(2,2) → 4!×2! = 48种

2. 插空法（不相邻问题）

  • 特征：某些元素”不能挨着”
  • 做法：先排其他元素，再把不相邻的插到空隙中
  • 例：3男生2女生站队，女生不能相邻 → 先排男生 A(3,3)，产生4个空位，插2女生 A(4,2) → 6×12 = 72种

3. 隔板法（同素分配）

  • 特征：相同物品分给不同人，每人至少1个

  • 做法：n个物品分m份，插(m-1)个板 → C(n-1,m-1)

  • n个物品会产生n+1个可以插的位置哦。但是左右边界不能查，n+1-2=n-1所有是Cm-1n-1

  • 例：10个苹果分给3人，每人至少1个 → C(9,2) = 36种

    4. 错位重排（信封问题）

  • 特征：每个元素都不能在原位置

  • 公式：D₁=0, D₂=1, D₃=2, D₄=9, D₅=44…

  • 例：4封信装错信封 → D₄ = 9种

n 元素 错位方案数 Dₙ 直观理解
1 A 0 A 只能在位置 1，无法错位
2 AB 1 只能 BA（1 种）
3 ABC 2 BCA、CAB（2 种）
4 ABCD 9 固定公式推导结果
5 ABCDE 44 固定公式推导结果

5. 分类讨论法

  • 特征：条件复杂，需分几种情况分别计算再相加
  • 做法：按限制条件分类，每类独立算后求和
  • 例：从5男3女中选3人，至少1女 → 分”1女2男””2女1男””3女”三类相加

6. 排除法（正难则反）

  • 特征：正面情况多，反面情况少
  • 做法：总情况数 - 不符合条件的情况数
  • 例：5人选3人，甲乙不同时入选 → 总C(5,3) - 甲乙都选的C(3,1) = 10-3 = 7种

工程问题

直接比例份数做

  • 基本关系：工作总量 = 工作效率 × 工作时间
  • 合作效率：多人合作时，总效率 = 各人效率之和
  • 关键思路：谁一直在干，谁中途休息了，要分开算工作量

题型 识别特征 解题方法

效率比例型 给出效率比或倍数关系 设效率为比例值，直接计算
轮流合作型 甲做一天、乙做一天交替 找循环周期，算剩余工作量
中途休息型 有人请假、停工 分段计算每人实际工作天数
双人双工程 两项工程、两人合作 优先分配擅长项，再合作收尾

先单独做，再合作

  • 个人总天数 = 单独做的天数 + 合作的天数
  • 例：甲先独做 5 天，再和乙合作 3 天 → 甲一共干了 8 天

周期问题

“只盯个位，找循环”

任何数字的幂次方，个位数只由底数的个位数决定，而且个位数的变化是有循环周期的。

和差倍比

题型 识别特征 核心公式/方法
和差问题 已知两数”和”与”差” 大数=(和 + 差)÷2，小数=(和−差)÷2
和倍问题 已知两数”和”与”倍数关系” **小数=和÷(倍数 +1)**，大数=和−小数
差倍问题 已知两数”差”与”倍数关系” 小数=差÷(倍数−1)，大数=小数×倍数
比例分配 已知比例求具体值 设每份为 x，按比例列方程

整数型

  • 特征：所求量为整数（人数、物品数等），题干有比例/分数
  • 做法：用倍数特性直接排错
  • 例：男生占全班的 3/7 → 全班人数是 7 的倍数，看选项锁定答案

2. 余数型

  • 特征：”除以 3 余 1””被 5 除剩 2”
  • 做法：找最小满足条件的数，再加公倍数通解
  • 例：一个数除以 3 余 1，除以 5 余 2 → 最小是 7，通解为 15k+7
  • ==通解就是：x = 最小公倍数(a,b) × k + 最小满足条件的数==

3. 给来给去型

  • 特征：两个主体之间互相转移数量
  • 关键：总量不变，抓住不变量列方程
  • 例：甲给乙 10 个后两人相等 → 原来甲比乙多 20 个

4. 同增同减型

  • 特征：两个量同时增加或减少相同数值a b.a+c b+c做茶还是a-b

  • 关键：差不变，利用差倍关系求解

  • 今年父亲的年龄是儿子的 4 倍，15 年后父亲的年龄是儿子的 2 倍。问今年父亲多少岁？

    • 今年：父:子 = 4:1 → 年龄差是 3 的倍数

    • 15 年后：父:子 = 2:1 → 年龄差是 1 的倍数

    • 年龄差不变，所以年龄差既是 3 的倍数，又是 1 的倍数

      代入选项验证

      （假设选项有 30、32、36、40）：

      • 若父亲 30 岁 → 儿子 7.5 岁 → 15 年后父 45、子 22.5 → 45÷22.5=2 ✓
      • 32 8 47 23不是2排除

5. 盈亏问题

  • 特征：分配物品时”多了几个、少了几个”
  • 公式：(盈 + 亏)÷(两次分配差)=人数
  • 例：每人分 3 个剩 10 个，每人分 5 个少 6 个 → (10+6)÷(5−3)=8 人
