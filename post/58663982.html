横线在中间

横线在中间时，重点看它前面说了什么、后面要说什么

错因：乱做，没有拿着承上启下的思维去做。

更没有抓住前面的重点！

横线前面在说什么？横线后面在说什么？

前面的重点是什么

后面的重点是什么？

  • 横线在开头 → 总领全文，概括后文核心话题
  • 横线在中间 → 承上启下，既要接住上文，又要引出下文
  • 横线在结尾 → 总结前文，或提出对策

忠于文段

细节判断

扩大范围

无中生有

偷换概念

细节判断题考的不是”你觉得对不对”，而是”原文有没有这么说

圈出关键词，回到原文找对应！

异曲同工VS同气连枝！

成语 核心意思 侧重什么 适用场景
异曲同工 不同的曲调演得同样好 方法不同，但效果一样好 两个人用了不同的做法，但都达到了很好的结果
同气连枝 如同同一气息、同一枝干上的枝条 同根同源、关系极其密切 形容兄弟姐妹或关系紧密的事物，强调”内在相连”

整体＞部分！

  • 看文段核心话题：如果文段在讲一个整体概念（比如”联觉反应””视听盛宴”），选项就尽量选能覆盖整体的，不要选只盯住某个局部的。
  • 看后文例子：例子往往是对横线内容的具体展开，如果例子体现的是整体感受，选项就不能缩小成局部问题。
  • **警惕”偷换范围”**：出题人特别喜欢用”部分”来干扰”整体”，看到选项把大概念缩小成小概念，直接警惕。

分号和句号！

  • 分号 → 并列关系（传感器内部四个并列：视觉、声音、力觉、触觉）
  • 句号 → 层次转换（从”传感器”转到”控制系统”）
  • 整体结构 → 并列两层（传感器 + 控制系统），需要全面概括
  • A项 → 只盖了传感器 + 结果，漏了控制系统 → 以偏概全
  • D项 → 传感技术 + 控制理论 + 集成 → 全面覆盖

挖坑思维撞词陷阱” + “偷换概念

带来好处的同时，坏处。

“在……的同时” → 后面大概率是转折，要填和前面相反或相对的内容

后文有”担心””引导””值得重视” → 说明前面在说问题，横线处必须填问题

套路一：撞词迷惑

  • 文段结尾有”文化素养“
  • C项也出现了”文化素养“
  • 你看到这两个词”撞在一起”，大脑就会自动产生”这俩有关系”的错觉

套路二：偷换概念

  • 文段讲的是网络数字媒介对未成年人的影响
  • C项偷换成了机器智能环境
  • 这两个概念根本不是一回事，但出题人故意用”文化素养”这个撞词来掩盖这个偷换

套路三：对策前置

  • 文段的逻辑是：好处 → 坏处 → 对策（最后才提出”值得重视”）
  • C项直接把对策”更需要思考……”提前放到横线处
  • 这样横线处就**没有填”坏处”**，导致前后文逻辑断裂

套路四：拔高立意

  • C项”机器智能环境下的文化素养提升”听起来很有高度、很深刻
  • 很多考生会觉得”这个选项好深刻，应该是对的”
  • 但实际上，深刻不等于正确，它和文段的核心话题根本对不上

“更需要思考”就是一个对策信号词，意思是”我们应该去做某事”。

经典片面！总句 > 分述 > 例子

“总句 > 分述 > 例子

B纯在说例子和分述！

把分述和例子当成了主旨，而C项抓住了总句。在总分结构中，总句永远大于分述和例子。

接语选择

下文延续尾句话题，而不是回头补前文

提出新概念/新策略 解释这个概念/策略的具体内容
提出问题 分析原因或给出对策
提出对策 展开对策的具体做法/实施细节
给出结论 举例论证或补充说明
  1. 尾句停在哪？
  2. 尾句里有什么新内容没展开？
  3. 哪个选项在顺着这个新内容往下说？

我的问题

吧D看错了。难耐高温，看成了耐高温的原因！

按照D的话可以放在前面问题后面。但是作者没有想放

如果改成耐高温的原因也不选！

问题：！敏感材料需要高温工艺，但柔性基底不耐高温。

解决：团队用“水溶性牺牲层辅助转移”策略，把“高温工艺”和“柔性基底”分步进行，让两者兼容。

这个策略并没有让柔性基底变得耐高温，而是绕过了基底不耐高温的限制。

  1. 尾句是亲爹，话题必须一致

  2. 前文已讲过的，不选

  3. 不要用自己的逻辑”补全文段”

具体大于模糊

例子永远不是重点

例子永远不是重点，例子是为了证明观点服务的。

首句提出观点 → 中间举例论证 → 尾句总结升华。重点在首句和尾句，中间例子直接略读。

D出题人意图：用首句的”交通”做干扰，让你觉得”交通是开头，肯定是重点”。

成语 含义 侧重点 感情色彩 巧妙记忆
娓娓道来 连续不断且生动详细地讲述，条理清晰、不疾不徐 强调讲述的方式生动、有吸引力 褒义 “娓娓” = 说话动听，像讲故事一样
和盘托出 毫无保留地陈述事实或表达观点 强调全面性、毫无保留 中性 “和盘” = 连盘子一起端出来，全倒出来
平铺直叙 说话或写文章不加修饰，没有起伏，重点不突出 强调平淡、无起伏 偏贬义 “平铺” = 平平淡淡地铺陈，没波澜
条分缕析 有条有理地细细分析 强调理性分析、层层拆解 中性 “条””缕” = 像理线头一样一条条分

“顺藤摸瓜“强调主动追查、层层深入，多用于调查案件等场景

“按图索骥“ = 拿着”图”（纪录片）去找”骥”（真实地点）

抓重点

结构类型 重点位置 解题技巧
问题 + 对策 对策 抓对策词（因此、需要、应该等），答案围绕对策
问题 + 对策 + 补充 对策 补充只是小尾巴，不能替代对策成为重点
转折结构 转折后 抓”但是””然而””不过”之后的内容
因果结构 结论 抓”因此””所以””因而”之后的内容

隐蔽性&隐秘性

维度 隐秘 隐蔽
核心字 秘 = 秘密、不公开 蔽 = 遮蔽、隐藏
侧重点 强调主观上保密，不想让别人知道 强调客观上不易被发现，藏在暗处
行为动机 主动保密、不让公开 被动隐藏、不容易察觉
常见搭配 隐秘行动、隐秘角落、隐秘性高 隐蔽场所、隐蔽性强、隐蔽起来
感情色彩 中性 中性
