政治理论

内容决定形式，形式服务于内容

会意识的形式决定内容 ✗ 内容决定形式

毛细血管展开：内容决定形式，形式服务于内容。社会意识的内容来源于社会存在（客观），形式是主观的表达方式。同一个内容可以有多种形式，但形式不能决定内容。

「普遍性寓于特殊性之中」

矛盾的普遍性寓于特殊性之中，并通过特殊性表现出来 ✓ 正确

毛细血管展开：共同规律＝矛盾的普遍性（共性）；各国特色路径＝矛盾的特殊性（个性）。共同规律不能凭空存在，必须通过各国的具体国情、特色道路体现出来——这就是「普遍性寓于特殊性之中」

企业是创新的主体

政府是创新的主体 ✗ 应为「企业」

毛细血管展开：企业是创新的主体——很多未来产业的兴起，是靠企业一步步突破带动的。政府的作用是营造环境、提供政策支持，不是「创新主体」。

减少投资规模，降低补助标准 ✗ 应「适当增加」「提高」

毛细血管展开：政策方向是——适当增加中央预算内投资规模，提高中央投资补助标准，优化实施「两重」项目。③把「增加」写成「减少」、「提高」写成「降低」，方向完全反了。
延伸：

「两重」= 国家重大战略实施 + 重点领域安全能力建设，资金主要来源是超长期特别国债，配合中央预算内投资。

龙头 = 国家实验室

发挥高水平研究型大学龙头作用，支持其牵头实施国家重大科技任务，探索新型科研组织模式 ✗ 龙头是「国家实验室」

毛细血管展开：这是本季最核心的「专属搭配」坑。
龙头 = 国家实验室。为什么？国家实验室是专门设立的超级平台，可以跨高校、跨院所、跨企业调集全国科研力量，发挥新型举国体制优势——它能「统筹」，所以是龙头。
高水平研究型大学的长处是学科多、人才多，擅长自由探索、产出原创思想、培养人才；但大学以课题组、学院为单元，很难跨单位大规模调度全国科研力量——所以它不能当「龙头」。
四大战略科技力量的定位：
· 国家实验室：龙头（系统层面、体系层面的总牵头）；
· 国家科研机构：建制化体系化优势，在战略高技术、公益性技术领域引领；
· 高水平研究型大学：基础学科、交叉学科的学术引领，基础研究主力军、人才培养主阵地；
· 科技领军企业：产业层面的引领（产业生态、技术标准）。

「发展南菜北运和冷凉地区蔬菜生产」不是高海拔地区

正确表述是「发展**南菜北运和冷凉地区蔬菜生产**」。
为什么不是「高海拔」？

因为冷凉地区包含两类——高海拔（云贵高原北部、青海、甘肃等）和高纬度（宁夏、甘肃等）。

只说「高海拔」，漏掉了高纬度，范围不完整。
南菜北运解决**冬春缺口**（南方温暖，冬天能种菜）

；冷凉地区（北菜南运）解决**夏秋缺口**（南方夏天高温，叶菜容易烂、减产，冷凉地区夏天凉爽，能产叶菜往南送）。两者配合，实现全年蔬菜均衡供应。

承包单位向分包单位及时支付账款，且保持同等现金支付比例

中央企业应当在合同中要求总承包单位向分包单位及时支付账款，且保持同等现金支付比例 ✓ 正确

毛细血管展开：这里有一条「资金链」——央企 → 总包 → 分包（中小企业）。过去的问题：央企付给总包「70% 现金 + 30% 商业汇票」，总包把 70% 现金截留，把 30% 汇票转给分包——中小企业拿到的全是汇票（到期才能兑付、贴现还要花钱），现金被总包截留了。
治理办法：总包收到央企的钱，要及时支付给分包，且保持同等现金支付比例（央企给总包 70% 现金，总包给分包也得 70% 现金），不能把现金截留、把票据往下甩。

商业汇票 = 「到期才能兑付的欠条」。中小企业拿到汇票，要么等到期（几个月后），要么去银行「贴现」（打折换现金，还要付贴现利息）。现金被上游截留、票据往下甩，中小企业的资金压力就大了。
治理核心：压账期、提现金比例、及时支付——让钱快点到中小企业手里

时间节点

二十届三中全会将习近平法治思想明确为全面依法治国的指导思想 ✗ 应为「2020年中央全面依法治国工作会议」

毛细血管展开：时间/会议错配——2020年11月中央全面依法治国工作会议首次正式提出习近平法治思想，并将其明确为全面依法治国的指导思想。二十届三中全会通过的是《中共中央关于进一步全面深化改革、推进中国式现代化的决定》，主题是「进一步全面深化改革」。①把两个会议搞混了。

二十届三中全会（2024年7月）审议通过《中共中央关于进一步全面深化改革、推进中国式现代化的决定》——这是当前和今后一个时期进一步全面深化改革的纲领性文件。
习近平法治思想：2020年11月中央全面依法治国工作会议首次提出。
两个会议，一个是「改革」，一个是「法治」，不要混。

「A 和 B 相统一」「A 和 B 相结合」，通常排在前面的更重要

坚持把社会效益放在首位，社会效益和经济效益相统一 ✓ 正确

毛细血管展开：两个效益——社会效益放在首位，同时「相统一」。为什么社会效益在前？因为文化产品有意识形态属性，不能只看赚钱。①正确。

文旅融合，「文」在前——文化体验是底色

推动文旅和相关领域融合发展，以经济交易为融合发展底色 ✗ 应以「文化体验」为底色

毛细血管展开：文旅融合，「文」在前——文化体验是底色。让文化为各类资源要素赋能，不是把「经济交易」当底色。④把「文化」换成「经济交易」，方向偏了。

以景区为中心，提升旅游服务质量 ✗ 应以「游客」为中心

毛细血管展开：旅游是服务业，服务对象是游客。以景区为中心，就变成「管理方便」而不是「游客满意」。正确是「以游客为中心」。②主体错配。

需求牵引供给

供需关系的完整表述：
· 供给创造需求：好产品能激发新需求（如智能手机创造移动支付需求）；
· 需求牵引供给：市场需求引导供给调整（如游客要深度游，倒逼景区开发新线路）。
二者结合，形成「需求牵引供给、供给创造需求的更高水平动态平衡」。

统筹层次

统筹层次要分清——
· 基本养老保险：全国统筹（已实现）；
· 基本医疗保险：省级统筹（推进中）。

资源 均衡配置 要素 自由流动

推进城乡之间公共资源均衡配置和要素自由流动 ✓ 正确

毛细血管展开：「资源」搭配「均衡配置」，「要素」搭配「自由流动」——两两对应。注意：资源用「均衡」，不用「均等」（均等通常搭配权利、服务）。

人 = 实际居住地；户 = 户籍登记地。「人户分离」就是让二者可以不一致——你在哪工作生活，就在哪登记户口、享受公共服务。
配套：**常住地**提供基本公共服务（教育、医疗、社保），不再和户籍绑定。

国家育人，**国家顶层设计**为先导

围绕国家战略需求协同育人，以统筹规划为先导，以改革为动力，以科学评价为牵引 ✗ 先导应为「国家顶层设计」

毛细血管展开：三个排序要记准——
① 国家顶层设计为先导（管方向、管全局）；
② 分类改革为动力（推动高校分类发展）；
③ 科学评价为牵引（评价指挥棒引导改革）。

排污许可制为核心的**固定污染源监管制度**

固定污染源：位置固定的排污主体——工厂、电厂、污水处理厂；
移动污染源：汽车、飞机、船舶。

排污许可制管的是「固定污染源」，因为位置固定、便于监管。

加快落实以补偿为核心的固定污染源监管制度 ✗ 应为「排污许可制」

毛细血管展开：固定污染源监管制度的核心是排污许可制——

环保部门给企业发「排污许可证」，证上写明：一年最多排多少二氧化硫、多少废水，配套什么治污设施。

企业在额度内按证排放，无证排污、超量排污、不按证要求改造治污设施的，都是违法。

「生态补偿」是地区之间的补偿机制（上游保护、下游补偿），不是「固定污染源监管制度」的核心。

④把「排污许可制」写成「补偿」，概念错。

严控城市开发边界

生态保护红线：生态功能最重要、必须严格保护的区域；

永久基本农田：保障粮食安全的「吃饭田」，原则上不许占用；

城镇开发边界：城市建设的「天花板」，**防止无序扩张**。
三条线都是「硬约束」，不能突破、不能放宽。

强化整体保护和合理利用，强化生态保护红线底线约束，放宽城镇开发边界管控 ✗ 应「严格」管控

毛细血管展开：三条控制线——生态保护红线、永久基本农田、城镇开发边界。三条线都要「严格管控」，不能「放宽」。

社会治理 「人民群众」主体作用

社会治理的主体是人民群众——群众是参与者、受益者、评判者。

政府是「负责」（提供公共服务、监管兜底），党委是「领导」（总揽全局），社会组织是「协同力量」。

社会治理的「四个角色」·

党委：领导（总揽全局、协调各方）；
· 政府：负责（公共服务、监管兜底）；
· 人民群众：**主体（参与、受益、评判）；
· 社会组织：协同（物业、企事业单位、社会组织）。
格局：共建共治共享**。

党的建设 · 责任链条

． 党委（党组）书记负主体责任，党委（党组）负第一责任人责任 ✗ 说反了

毛细血管展开：责任链条是——
· 党委（党组）：负主体责任；
· 党委（党组）书记：负第一责任人责任；
· 纪委：负监督责任；
· 班子成员：落实***一岗双责***。

制度执行的关键是「关键少数」

一个地区、一个部门的制度执行得好不好，关键在基层党员群众 ✗ 关键在「一把手」/领导干部

毛细血管展开：制度执行的关键是「关键少数」——一把手、领导干部。为什么？

一把手带头执行，下面才不敢破例；一把手自己不守制度，下面就有样学样。

基层党员群众是执行者，但不是「关键」。

总结

  1. 辩证否定 = 联系发展的环节，实质扬弃；内容决定形式，不是形式决定内容。
  2. 共同规律 + 各国特色 = 普遍性寓于特殊性。
  3. 实体经济立身之本、根本源泉、重要支柱；投资于物和投资于人紧密结合。
  4. 企业是创新主体；投资要增加、补助要提高。
  5. 龙头 = 国家实验室（不是高水平研究型大学）。
  6. 三个重中之重：三农问题、粮食供给、产业振兴；冷凉地区 = 高海拔 + 高纬度。
  7. 贸易投资一体化，不能「独立发展」。
  8. 账期要压减、现金支付比例要提高。
  9. 习近平法治思想 = 2020 年中央全面依法治国工作会议。
  10. 社会效益放在首位；育人才建队伍是战略任务。
  11. 旅游以游客为中心；文旅融合以文化体验为底色。
  12. 结构性就业矛盾靠技能培训；养老保险全国统筹、医疗保险省级统筹。
  13. 常住地登记户口（不是户籍地）。
  14. 以治病为中心 → 以健康为中心（方向不能反）。
  15. 国家顶层设计为先导、分类改革为动力、科学评价为牵引。
  16. 固定污染源监管核心 = 排污许可制（不是补偿）。
  17. 三条控制线严格管控（不放宽）；海域使用权市场化配置比例要提高。
  18. 社会治理主体 = 人民群众（不是政府）。
  19. 党委负主体责任、书记负第一责任人责任。
  20. 制度执行关键在一把手（不是基层群众）。
