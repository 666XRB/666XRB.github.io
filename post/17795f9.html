否一推一 凡。。否。。。

“凡 A 都 B”本质就是“所有 A 都是 B”或者“只要是 A 就一定是 B”，属于标准的前推后（充分条件假言）。

当某个条件推出“A或B”时，那么A或B这两个只要有其中一个被否定了，另一个就能够被推出来

相关≠有因果关系

这种就是归因性题干：说 A 与 B 相关，就推出 A 能够治疗 B，或者反正 A 与 B 有关系，A 能治疗 B，A 是 B 的结果。

认识论 有限性与无限性

有限性：对应每一个时代、每一个人的认识——受主客观条件制约，都是有限的。
无限性：对应整个人类——人类世代延续，面对无限发展的客观世界，认识具有无限性。
正确表述：人类的无限认识存在于一代代人的有限认识当中，并通过无数有限性的认识而得以实现。

★ 思维的至上性与非至上性****思维的至上性：人类整体思维能力是无限的，可以不断认识世界。
思维的非至上性：每一个人、每一个时代、每一代人的认识能力都是有限的。

党对军队的绝对领导是人民军队的***建军之本、强军之魂*； 党建
· 政治建军是人民军队的*立军之本*，关乎国防和军队现代化建设的方向和底色**红的 政治！。

怎么理解？没有党，哪来的军队？——所以党的领导是「建军之本」；建完军队要把这支军队立得住、立得久，要靠政治——所以政治建军是「立军之本」。

一般说「归根到底要落到人的身上」，但国防和军队现代化目标任务的表述是「归根到底要靠各级党组织来领导推进」。
党组织也是由人组成的，但这里强调的是组织领导的维度。

基层党建

★ 核心辨析：民主集中制 vs 批评与自我批评·

民主集中制是党的根本*组织原则和领导制度***；
· 批评与自我批评是党的三大优良作风之一。

多边主义 「主权平等、相互尊重」根本原则 反对 零和博弈

★ 核心辨析：我国外交的根本原则

我国奉行**不结盟政策，摒弃零和博弈思维**，反对结盟、反对零和博弈。
根本原则是：主权平等、相互尊重。

★ 关键搭配速记· 遵守法治 → 必然要求；
· 多边主义（不是单边主义）→ 我们践行的；
· 对话协商 → 关键路径；
· 互利共赢、普惠包容 → 发展方向；
· 均衡有序 → 注意是「均*衡有序*」，不是「均等」**。

市场化培训为主导****「政府培训为主导」一眼错

人力资源（包括劳动力）作为一种资源，市场对资源的配置起决定性作用。

以市场化培训为主导，行业企业自主培训为主体，充分发挥院校、社会化培训机构等优势作用，扩大高质量培训供给。

「一老一小」 「人口平均预期寿命稳步提高」社会主义制度优越性的体现

挖坑点一：②「人口出生率」→ 应为「人均预期寿命」我国人口总和生育率目前是在走低的，「出生率稳步提高」这个表述与事实不符。
正确表述：人口平均预期寿命稳步提高，是我们社会主义制度优越性的体现。

★ 核心辨析：调节过高收入 ≠ 降低高收入正确表述是**扩大中等收入群体、增加低收入者收入、调节过高收入——是「调节」，不是「降低」。

常识

婚姻无效

无效、可撤销 → 法律上等于”没结过婚“（恢复单身人设）；离婚 → 法律上”结过婚“。

「婚内分财产，两种情况：一方重病要医治，对方不肯掏钱；一方偷偷转移、挥霍共同财产。」

必背 婚姻无效的三种情形；可撤销婚姻的两种情形（隐瞒重大疾病是可撤销，不是无效——高频陷阱）。
必背 无效/可撤销 vs 离婚 的区别（自始无效 vs 生效日起解除）。
必背 婚内可请求分割共同财产的两种情形。
理解 赌博、吸毒等恶习屡教不改 → 调解无效应准予离婚。

回避绝对权

  • C. 药店负责人申请审判人员张三回避，应当由审判委员会决定——错误。审判人员回避由院长决定；只有院长担任审判长时的回避才由审判委员会决定。故选 C。
  • 回避决定权的三级划分（审委会 / 院长 / 审判长）——极高频。
  • 当事人对回避决定不服可复议一次。
    行政复议、行政诉讼中适用简易程序的条件（事实清楚 + 权利义务明确 + 争议不大 + 各方同意）。

谁来决定、决定前要不要暂停、不服怎么办。

「申请被驳回，可以复议一次；决定前要暂停，紧急除外；决定可书面可口，口头记笔录。」

为什么要暂停？因为如果法官不回避，后续庭审可能程序违法，整个庭审要重来。

职务侵占罪 侵占罪

侵占罪与职务侵占罪的唯一区分标准：**是否利用职务便利。**

挪用**公款** vs 挪用**资金**——主体不同（国家工作人员 / 公司企业人员）

贪污罪 vs 职务侵占罪——主体不同（国家工作人员 / 非国家工作人员）。

侵占罪的特点是”合法持有 → 非法占有“（代为保管的财物、遗忘物、埋藏物）。

挪用公款罪两个条件：「盈利活动 + 超三个月未还，两个都占才构成。」

③ 诈骗罪三要素：「非法占有目的 + 虚构/隐瞒 + 数额较大。」

救助可主动上门，终止要白纸黑字

受助人通过就业获得稳定收入，社会管理部门可以依法作出终止社会救助的决定，并口头告知——错误。终止社会救助应当书面告知受助人，并说明理由。

凡是行政上涉及”终止、撤销、驳回、不予受理”等影响当事人权益的决定，一般都要求**书面 + 说明理由**，纯口头的一定是错的。

必背 社会救助可以主动实施，无需等待个人申请。
必背 终止社会救助须书面告知 + 说明理由。
理解 骗取社会救助的后果：退回 + 罚款，构成犯罪追刑责。
了解 申请社会救助应如实报告家庭收入和财产状况。

不公平格式条款无效（不退不换、最终解释权等）。

不公平、不合理的格式条款，无效；且商家存在欺诈。

弧圈球不是靠”空气浮力”，是马格努斯力

本质为伯努利原理

球一边向前飞、一边高速自转，会带动周围空气，使球体两侧空气流速不同 → 产生压强差 → 出现横向的马格努斯力，飞行轨迹拐弯。底层原理是伯努利原理。

伯努利原理：流速越大，压强越小；流速越小，压强越大。

浮力 = 排开空气/液体所受的重力，和旋转没关系。

「二氧化硅是酸性氧化物，只跟强碱和氢氟酸玩。」

「装碱用橡胶塞，不用玻璃塞」——因为玻璃中的 SiO₂ 与碱反应生成有粘性的硅酸钠，会把瓶塞粘死。

「三氯蔗糖甜但不产热，糖尿病人放心用。」

苯甲酸钠属于酸性防腐剂，特定条件下可与维生素 C 反应生成苯

苯有毒性。

亚硝酸钠兼具氧化性与还原性。

灼烧闻气味可区分天然羊毛与合成纤维

水垢主要成分是碳酸钙，小苏打是**碳酸氢钠，几乎不反应。除水垢要用酸性**物质（食醋、醋酸）。

. 加碘盐中添加的是碘化钾——错误。现在添加的是碘酸钾；碘化钾不稳定、易分解流失，已很少使用。

氯化铝是共价化合物，熔融时不电离出自由移动的离子，不导电，无法电解。工业上电解熔融氧化铝（加冰晶石降熔点）制铝。

羊毛是蛋白质，灼烧有烧焦羽毛气味；合成纤维灼烧有刺激性塑料气味。

「除水垢用酸，不用碱。」
② 「碘盐加的是碘酸钾，不是碘化钾。」
③ 「制铝电解氧化铝，氯化铝是共价不导电。」
④ 「羊毛烧出羽毛味，化纤烧出塑料味。」

真菌依靠孢子繁殖。

脚气、灰指甲由真菌引起；酸奶、泡菜由乳酸菌（**细菌**）发酵。
