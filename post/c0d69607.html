政治理论

统一**市场监管执法**，这是市场运行秩序和资源配置效率的有效保障

党的自我革命的利器是从严监督执纪

。持续用党的创新理论统一思想、统一意志、统一行为，发展党内民主，健全落实民主集中制。这个“三统一”，用的是党的创新理论

党的自我革命，重在治权

宪法的生命在于实施，宪法的权威也在于实施

模考政治理论

我国已建成世界上规模最大的教育体系，教育现代化发展总体水平跨入世界中上国家行列；

建成世界上规模最大的教育体系”是党的二十大以来的固定表述

跨入世界中上国家行列”出自《中国教育现代化 2035》中期评估

把加强教师队伍建设作为建设教育强国最重要的基础工作来抓。

立德树人是根本任务，”三问”是根本问题和核心课题

培养什么人、怎样培养人、为谁培养人是教育的根本问题，也是建设教育强国的核心课题。

探索以词元为基础的价值体系

token！

不是词条！
数据标注从”以人为本”向”人机协同、专家深度参与“转变——标注是数据集建设不可或缺的关键环节。

“执大象，天下往“

“大象”即”大道”、根本规律。掌握大道、顺应规律，天下人自然归往——体现的正是尊重客观规律、按规律办事。

看到”天下往”就联想到”人民群众”——这是最典型的语感误判。古文题的关键是抓”题眼”（大象 = 大道 = 规律），而不是抓”感觉”。

“道””理””势””时””法”→ 规律；”民””众””心”→ 群众史观；”变””化””新”→ 发展观；”两””对””矛”→ 矛盾观。

形成市场主导的有效投资内生增长机制

完善完全由市场供求关系决定要素价格机制

完善**主要由市场供求关系决定要素价格机制””推进能源、铁路、电信、水利、公用事业等行业自然垄断环节独立运营和竞争性环节市场化改革””形成市场主导**的有效投资内生增长机制”。

政府主导的有效投资内生增长机制。❌

形成市场主导的有效投资内生增长机制✅

进入市场前/后这个分水岭

现在讲粮食安全，实际上是食物安全，保障食品安全是践行大食物观的前提；

❌农业农村部门负责履行食用农产品**进入批发、零售市场后**的质量安全监管职责；

—农业农村部门管”田头”，市场监管部门管”市场”。

凡涉及”从农田到餐桌”全链条监管的题目，一定要盯住”进入市场前/后”这个分水岭。

**县级**市场监管部门及其派出机构以食品安全为首要职责

整治形式主义为基层减负 原则上不得借调

原则上不得

严格规范从县乡借调干部””原则上不得借调”，《整治形式主义为基层减负若干规定》并非”一律不得”，且存在必要的例外情形。**”一律不得”绝对化。**

高质量充分就业

  • 国有企业 → 就业引领作用
  • 民营企业 → 吸纳就业主渠道
  • 中小微企业 → 就业蓄水池
  • 政府 → 兜底帮扶、政策支持

土地问题”两个不允许”：“三个不得”**

  • 不允许城镇居民到农村购买农房、宅基地
  • 不允许退休干部到农村占地建房
  • 土地流转”三个不得”：不得**下指标、不得定任务、不得将流转面积和比例纳入政绩考核**。
  • 推动转移支付、新增建设用地指标、基础设施建设投资等与农业转移人口市民化挂钩 ✓

提高村庄规划编制质量和实效，不得要求村庄规划编制全覆盖

**发展是党执政兴国的第一要务 **⭐️⭐️⭐️

扩大内需（不是扩大出口）是推动高质量发展的战略基点

不追求增速最大化，而是”质的有效提升和量的合理增长”。

高水平科技自立自强是发展的战略支撑

没有高水平创新就没有高质量发展”过于绝对。

必备

  • 扩大内需 → 战略基点
  • 供给侧结构性改革 → 主线
  • 高质量发展 → 首要任务（全面建设社会主义现代化国家的首要任务）
  • 教育、科技、人才 → 基础性、战略性支撑
  • 科技自立自强 → 战略支撑
  • 发展 → 党执政兴国的第一要务

生态文明类题目中，”以经济建设为中心”几乎总是错误选项，

激发各类经营主体的内生动力和创新活力

不是”集中全力激发非公有制经济”

“两个毫不动摇”要求公有制经济和非公有制经济**一视同仁**。

社会工作体制机制 新经济组织、新社会组织、新就业群体“（”三新”）党的建设

而非”混合所有制企业、非公有制企业”。这是 2024 年中央社会工作会议的新提法。

  • 旧提法：”两新”组织 = 新经济组织 + 新社会组织
  • 新提法：”三新” = 新经济组织 + 新社会组织 + 新就业群体
  • “混合所有制企业、非公有制企业”党建是传统领域，不是中央社会工作会议强调的新兴领域。

健全”以职业道德、能力素质、业绩贡献为导向”的评价机制

新兴产业 未来产业

  • 特点：前瞻性、战略性、颠覆性、高风险、高投入、长周期。
  • 未来产业的特点恰恰是高风险、高不确定性

工人阶级和工会工作

  • 工人运动的时代主题 → 为实现中华民族伟大复兴的中国梦而奋斗
  • 工会的政治责任 → 把广大职工和劳动群众紧紧团结在党的周围
  • 工会工作的关键 → 坚持正确政治方向

2035 年对应的是”基本实现”，不是”全面建成”；”全面建成”对应的是 2050 年前后。

建军一百年2027 2035年 基本实现社会主义现代化

碳中和（2060）vs 碳达峰（2030），这是双碳目标的经典混淆点。看到”碳”字先问自己：是达峰还是中和？时间对得上吗？
