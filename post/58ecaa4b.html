政治理论

马哲 · 量变质变 / 主要矛盾

精细化改造推动城市治理实现质的跃升。上述内容蕴含的哲学道理，下列正确的是？

① 事物发展是量变与质变的统一 ✓ 精细化改造是量的积累，最终实现城市治理模式质的跃升

② 矛盾的主要方面决定事物的性质，城市微更新要聚焦民生短板、把握城市主流 ✗ 「聚焦」对应主要矛盾，「主流」对应矛盾主要方面，搭配错位

③ 实践是认识的来源和发展动力，城市微更新实践推动治理理念迭代升级 ✓ 新实践推动治理理念从粗放走向精细

④ 事物发展是前进性与曲折性的统一，城市微更新彻底规避城市建设的各类问题 ✗ 「彻底规避」绝对化，且材料未体现曲折性

精细化改造就是量的积累

「精细化改造」是一点一点、不显著的改变，这叫量变；「城市治理模式质的跃升」是根本性质的变化，这叫质变。

★ 量变质变三句话（公考只考这三句）① 量变是质变的必要准备——任何质变都必须先经过量的积累，没有量变就没有质变；
② 质变是量变的必然结果，质变又为新的量变开辟道路；
③ 量变和质变相互渗透——总的量变过程中有部分质变，质变过程中又有量的扩张。
⚠ 不能说「量变必然引起质变」——量变要达到一定的度才会引起质变。

★ 关键词法：主要矛盾 vs 矛盾主要方面****主要矛盾：重点、中心、关键、首要、突破口、聚焦、抓短板——侧重办事情、干工作、解决问题。
矛盾主要方面：主流、支流、总体上、利弊、评价、性质、好坏——侧重看问题、作评价、判断性质。
⚠ 「聚焦主流」在规范表述中是错的：聚焦对应主要矛盾，主流对应矛盾主要方面。民生短板是众多矛盾中需要重点解决的，属于主要矛盾。

辩证否定 = 扬弃

产业转型意味着对传统产业的彻底否定 ✗ 形而上学全盘否定

新技术的引入是传统产业实现质变的内因 ✗ 新技术属于外部条件，是外因

新旧产业要素的更替说明事物发展是循环往复、简单重复 ✗ 发展是螺旋式上升、波浪式前进

辩证否定 = 扬弃辩证否定不是全盘抛弃，而是既克服又保留：克服旧事物中落后消极的因素，保留积极合理的因素，实现产业迭代升级。
发展不是循环往复、简单重复，而是螺旋式上升、波浪式前进。

内因与外因****内因是事物内部的矛盾，是事物变化发展的根据；外因是事物外部的条件，是事物变化发展的条件。
传统产业自身内部的矛盾才是质变的内因；新技术引入属于外部条件，是外因。

基础研究

基础研究要坚持自由探索为主、目标导向为辅 ✗ 应坚持目标导向和自由探索并重

目标导向：通过有组织的技术研究、应用技术研究，解决技术科学和工程科学的薄弱问题，瞄准现实短板、解决「卡脖子」工程技术难题，服务国家急需。
自由探索：鼓励科学家好奇心驱动，开拓全新知识疆域，为未来几十年储备原始创新，很多颠覆性技术就来自自由探索。
二者不是谁主谁辅，而是*目标导向和自由探索并重*。一旦说成「为主/为辅」，就是错。

耕地三概念⭐️⭐️⭐️

农业是立国之本、强国之基，重农固本是安民之基、治国之要；推进乡村全面振兴，提升农业综合生产能力和质量效益 ✓

② 牢牢守住 18 亿亩耕地红线，逐步把一般耕地全部建成高标准农田 ✗ 应把永久基本农田全部建成高标准农田

③ 强化农业科技和装备支撑，健全种粮农民收益保障机制和主产区利益补偿机制 ✓ 不是主销区

④ 建立以市场需求为导向的农产品品质评价和质量分级制度 ✓ 品质、口感、等级由消费市场决定

· 一般耕地：全部耕地中除去永久基本农田后剩下的部分，管控相对松，可种粮、棉、油、糖、蔬菜等；
· 永久基本农田：依法划定、实行**永久特殊保护的优质耕地**，原则上占辖区耕地 80% 以上，主要用于稻谷、小麦、玉米生产，原则上不允许占用，重大项目占用需报国务院批准；
· 高标准农田：通过人工工程改造（平整土地、修水渠、修路、通电），做到集中连片、旱涝保收、高产稳产。
⚠ 国家政策是把「永久基本农田」全部建成高标准农田，不是一般耕地；高标准农田的前身可以是一般耕地，也可以建在条件好的一般耕地上。

永久的 建成 高标准

以补定占主要针对一般耕地先算出能补出多少耕地，再决定最多可占用多少耕地。永久基本农田保护极其严格，原则上不允许占用，所以「以补定占」主要制衡的是一般耕地。

补偿方向是主销区补主产区（省际横向利益补偿），所以是「主产区利益补偿机制」，不是主销区。

政府引导带动，市场主导

中央财政减少对地方财力性转移支付规模 ✗ 应增加

转移支付是什么：中央把一部分财政收入转移给地方，用于平衡地区间财力差距、保障基层运转（教师工资、社保、基本公共服务）。
为什么现在要增加：当前地方财政压力大——土地出让收入下降、减税降费、基层「三保」（保基本民生、保工资、保运转）压力突出。中央增加对地方财力性转移支付，就是给基层「输血」，保障基层正常运转和民生支出。
为什么「减少」错：减少转移支付会加剧地方财政困难，与当前「加大对地方支持力度」的政策方向完全相反。而且这种话不可能拿到明面上说——政治素养也能判断。

加强中央事权，不是地方事权。提高中央财政支出比重

：事权是「这件事谁负责办」；支出责任是「办这件事的钱谁出」。改革方向是「适度加强中央事权和支出责任」——一些原本交给地方办的事（如跨区域事务、基础科研），中央自己承担起来，给地方减负。

坚持平等保护，增强政府主导的有效投资政策动力 ✗ 应为市场主导，政府引导带动

政府投资：扮演的是「引导、带动、撬动」角色。政府资金是「种子钱」，四两拨千斤——政府投 1 亿，释放国家战略方向信号，吸引社会资本投 100 亿。政府不是投资的主力。
市场投资：才是「主导」。社会资本是投资政策的主力，市场在资源配置中起决定性作用。
所以正确表述是：市场主导的有效投资，政府引导带动

央地投入共担机制

完善中央财政科技经费支配和管理使用机制，重大科技任务由中央主要承担、地方补充 ✗ 应「央地投入共担」

重大科技任务（如关键核心技术攻关、重大科技基础设施）往往涉及央地共同事权，需要中央和地方共同投入、共担风险。如果只说「中央主要承担、地方补充」，就把地方降为「配角」，不符合**「央地协同、共同发力」**的改革方向。

健全央地投入共担机制——中央和地方按事权划分共同分担投入，提高投入绩效。

科技创新要突出效益导向，高校科研院所对接企业 ✗ 应突出「应用导向」

应用导向：强调科技**成果要对接产业实际应用**，打通从科研到生产力的转化——高校科研院所对接企业，正是因为企业离实际应用最近、离成果转化最近。
效益导向：强调投入产出、要赚钱。高校科研院所是基础研究、原始创新的主力，不是去赚钱的，说「效益导向」就把格局说低了。
所以是应用导向，不是效益导向。

我国正从全球科技参与者、贡献者向开拓者和引领者转变 ✗ 本项表述本身正确，但按讲解本题选 D

过去和现在我们产出大量论文、专利、技术成果，为全球科技进步输出成果，是参与者、贡献者；开拓者、引领者是未来要努力抵达的目标身份

深入推进商品和要素流动型开放 稳步推进制度型开放 有序扩大服务业

技术是未来产业最宝贵的**资源**，要在全社会营造鼓励创新、宽容失败的氛围 ✗ 应为「人才」

未来产业最宝贵的资源是人才，不是技术。

技术是人创造出来的，鼓励创新、宽容失败，鼓励和宽容的对象都是人。技术是死的，人才是活的。人才是第一资源，创新是第一动力，科技是第一生产力——「三个第一」要分清：人才是第一资源。

  1. 要**稳步扩大制度型开放，进一步提高贸易投资自由化便利化水平。\n深入推进商品和要素流动型开放**，更好促进生产要素跨境流动
  2. **有序扩大**服务领域自主开放
  3. 服务领域开放涉及金融、电信、医疗、教育等敏感领域，必须统筹安全与发展——有序开放，成熟一项推一项，不能一下子全面放开。看到「全面扩大」先想是不是「有序扩大」。

· 内需：拉动经济增长的主动力和稳定锚；
· 消费：对经济增长起基础作用；
· 投资：对优化供给结构起关键作用。

消费按目的分类

提高改善型消费比重，适应服务需求，规范发展教育和培训 ✗ 教育培训属于「发展型」消费

嵌入式服务：把养老、托育、助餐等服务嵌入社区，居民步行可达；便民生活圈：一刻钟便民生活圈。两者都是提高生活服务消费便利化的具体举措，一一对应。

消费按目的分三类：
· 生存型消费：满足基本生存刚需——吃饭、基础衣物、基础住房；
· 发展型消费：提升自身素质、能力，投资于人——教育培训、职业技能培训、成人学习；
· 改善型（享受型）消费：满足享乐、休闲体验、生活品质——演唱会、旅游、游轮、露营。

区分关键就是一句话：有没有提升自己的能力。教育培训提升能力 → 发展型。

区分发展型和改善型的关键：看有没有提升自己的能力。教育培训是提升能力 → 发展型；旅游是休闲享受 → 改善型。

党的建设总体布局：统领与基础

· 政治建设：统领（管方向、管根本）；
· 思想建设：基础（管理想信念、管理论武装）；
· 组织建设：优势所在、力量所在；
· 作风建设：保持党同人民群众血肉联系；
· 纪律建设：治本之策；
· 制度建设：长远之策、根本之策；
· 反腐败斗争：一体推进三不腐，重要方略。

以经济实力推动国防实力提升 挖坑是否是双向？

军地统筹、衔接、共享，要求**经济实力与国防实力**双向互促、同步提升。

「以经济实力推动国防实力」是单向逻辑——只强调经济支撑国防，忽略了国防对经济的拉动（军工技术转民用、国防建设带动产业升级）。军地统筹是双向的，不是单向的。

听党指挥是灵魂——决定军队建设的政治方向；
能打胜仗是核心——反映军队根本职能和军队建设的根本指向；
作风优良是保证——关系军队性质、宗旨、本色。
⚠ 人民军队一切建设和工作要聚焦「能打胜仗」。科技是核心战斗力。

战斗力 = 人 + 装备 + 编制 + 训练 + 保障的综合。只看装备水平是片面的。人民军队一切建设和工作要聚焦「能打胜仗」——能打胜仗就是战斗力的体现。

警惕高速发展 高速俩字！

统筹新能源发展和国家能源安全，坚持规划先行、加强顶层设计，推动新能源高速发展 ✗ 应为「高质量发展」

新能源发展要高质量发展，不追求速度。

新能源（风电、光伏）发展面临消纳能力、电网稳定性、储能配套等约束，盲目追求「高速」会导致弃风弃光、电网安全问题。所以是「高质量发展」——量的合理增长 + 质的有效提升 + 安全可靠。

源头管控 vs 源头减量：特殊三链条

一般安全治理：源头管控。
重点行业绿色化改造特殊三链条：源头减量 → 过程控制 → 末端高效利用。

坚持极限思维、底线思维，落实防汛防台风各项措施，加强各类风险隐患排查整治 ✓ 正确

「极限思维」= 往最坏处想；「底线思维」= 守住最低防线。防汛防台风正是用极限思维和底线思维——宁可十防九空，不可失防万一。

节能降碳 配额总量 强度管控 搭配

对碳排放总量快速增长的行业优先实施配额总量控制 ✗ 应对「相对稳定」的行业优先实施

配额总量控制 vs 强度管控：毛细血管版

维度 配额总量控制 强度管控
管什么 碳排放总量（天花板） 单位产品碳排放强度
适用行业 总量相对稳定的行业（如钢铁） 总量**快速增长**的行业
为什么 波动小，能定合理稳定的总配额 波动大，总量天花板难确定

配额总量控制：给行业定死一个碳排放天花板，一年只能排这么多碳。前提是行业碳排放总量相对稳定——如钢铁，产能、排碳规模已基本稳住，波动小，才能确定合理稳定的总配额。
快速增长的行业：产量还在扩张，碳排放总量波动大，很难确定合理稳定的总量天花板。对这类行业，适合强度管控——管单位产品的碳排放强度，而不是管总量。

党建

民主集中制作为党的根本组织原则和领导制度，必须在领导班子议事决策中全面贯彻。

全面从严治党关键在从严治吏，坚持党管干部原则，坚持德才兼备、以德为先 ✓ 正确 德 不是才！！！

管好领导干部这个「关键少数」。选人用人标准是德才兼备、以德为先——**德在前、才在后**，政治标准放在首位

新兴领域 传统领域

倡导普惠包容的经济全球化，拓展贸易投资、互联互通、能源资源等新兴领域 ✗ 这些是「传统领域」

传统领域：贸易投资、互联互通、能源资源——合作已经比较深，用巩固。
新兴领域：人工智能、数字经济、绿色产业、绿色矿产等——合作还在起步，用拓展。

坚持大小国家一律平等，地区事务共商共建共享，聚同化异，对话协商妥处矛盾分歧 ✓ 正确

「大小国家一律平等」是主权平等原则；「共商共建共享」是全球治理观；「聚同化异」是凝聚共识、化解分歧；「对话协商」是解决矛盾的路径。全是规范表述。

「防止」制度成为稻草人

推动制度成为稻草人 ✗ 应「防止」制度成为稻草人

稻草人 = 插在田里一动不动、起不到威慑作用的假人。制度成为稻草人，就是制度形同虚设——写在纸上、挂在墙上，就是不执行。

职工代表大会是企事业单位民主管理的基本形式，完善它是基层民主建设的重要内容。

教育的三重属性：政治、人民、战略· 政治属性：培养社会主义建设者和接班人；
· 人民属性：办人民满意的教育；
· 战略属性：国之大计、党之大计。

他因削弱

共因削弱

共因（另有共因）的完整逻辑是：题干说”A 导致 B”，选项指出有一个共同原因 C，同时导致了 A 和 B，从而说明 A 和 B 之间根本没有因果关系，只是”同病相怜”。

结构是：C → A 且 C → B

举个例子你就懂了：

题干：冬天穿羽绒服的人多了，感冒的人也多了 → 所以穿羽绒服导致感冒。 共因削弱：寒冷导致人们穿羽绒服，也导致感冒 → 穿羽绒服和感冒只是同时发生，没有因果关系。

只是给”环保”又找了一个原因，这属于补充另一个原因，而不是共因削弱。

伪他因 没有回归实验 泛泛而谈的说除了。。。还有。。。那就是伪他因

看选项是否明确指向实验中的分组，是否说明”实验组有 XX 额外特征，而对照组没有”。

  • 回归实验（真他因）：”吃白米饭多的人，其他类型食物的摄入量也高”——明确指向”吃白米饭多”这个实验组，说明他们还有另一个特征（吃其他食物也多）。
  • 没回归实验（伪他因）：”遗传等因素也会增加患糖尿病风险”——只是泛泛说遗传能导致糖尿病，但没说”吃白米饭多的人遗传更差”。

邯郸学步：比喻一味模仿别人，不仅没学到本事，反而把原来的本事也丢了。

  • 问题：它侧重的是”模仿别人→失去自我”

穿凿附会：指生拉硬扯，把没有关系的事物硬拉到一起，勉强解释。

  • 问题：它侧重的是”解释牵强、逻辑不通”

隔靴搔痒：比喻做事没有抓住关键，不解决问题，徒劳无功。

  • 问题：它侧重的是”没抓到要害、不解决问题”

削足适履：比喻不顾事物本身的客观实际和固有规律，为了迁就外在的标准和要求，强行改变事物本身，生搬硬套。

  • 完美契合！”足”是”中国实践”，”履”是”西方概念”，”削足”就是”强行改变中国实践去迎合西方概念”，”适履”就是”勉强迁就”。

对应

刚愎自用只对应”盲目自信”，**没有覆盖”妄自菲薄”**，维度不对齐

刚愎自用：固执己见，自以为是，不听别人意见。

侧重的是”固执、不听劝”，但题干第二空说的是”盲目自信或者妄自菲薄”——既可能过高估计自己，也可能过低估计自己。刚愎自用只对应”盲目自信”，**没有覆盖”妄自菲薄”**，维度不对齐。

坐井观天：坐在井底看天，比喻眼界狭小，见识短浅，对自身和环境的认知有偏差。

坐井观天的人既可能”盲目自信”（觉得天就井口那么大，自己看得很准），也可能”妄自菲薄”（觉得自己只能看到井口那么大）。它涵盖了对自身认知的偏差，和”盲目自信或者妄自菲薄”的语义更匹配。

头重脚轻 虎头蛇尾

头重脚轻：比喻基础不稳固或结构不合理，上面重下面轻。

侧重的是”结构失衡”，但题干第二空要和”前紧后松”并列，”前紧后松”强调的是时间维度上的前后不一致（前期紧、后期松），而”头重脚轻”是空间维度的结构问题

虎头蛇尾：比喻开始时声势很大，到后来劲头很小，有始无终。

侧重 开始的时候声势大，结尾小

对应不能对应错了！对应的重要性！

揣摩 满足 本末倒置 曲意逢迎

  • 揣摩：反复思考推求，揣度别人的心思。”揣摩法官个人偏好”非常贴切，说明法律从业者在费心思去猜法官喜欢什么。
  • 本末倒置：把根本和枝节搞反了。题干中”案件事实与法律条文”是”本”，”法官个人偏好”是”末”，把精力花在偏好上而忽视事实，正是本末倒置。
  • 预判：预先判断。”预判法官偏好”语感上可以，但不如”揣摩”精准，因为”预判”偏向理性分析，而题干强调的是”费心思去迎合”。
  • 虚与委蛇：假意敷衍应酬。
  • 。”满足”通常是”满足某人的需求”，但”偏好”是主观倾向，不能用”满足”搭配，应该是”揣摩”或”迎合”。

更迭 正襟危坐 覆盖 堆彻

更迭：交替、轮换。强调新旧替换，但题干说的是”新旧并呈、难解难分”，不是”旧的被新的替换掉”。

  • 寥寥无几：形容数量非常少，少得没几个。强调数量极少，适用范围广，中性词。
